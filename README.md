# Web Programming 1 Project | BWP401

## 🎓 Virtual University Events Guide - SVUEG

This project was developed as a practical application for the **Web Programming 1 (BWP401)** course. It aims to build a complete website that displays events for the Syrian Virtual University using basic web technologies.

Live Demo: [https://muaazhbobati.github.io/Syrian-Virtual-University-Events-Guide-SVUEG-/]
---

## 🎯 Requirements Implemented

| Requirement | Status |
|-------------|--------|
| 5 HTML pages (Home, All Events, Event Details, About, Contact) | ✅ |
| Header + Main + Footer structure on each page | ✅ |
| Responsive design (Flexbox/Grid + Bootstrap Grid) | ✅ |
| Suitable colors and fonts | ✅ |
| Slider for featured events | ✅ |
| Filter by category, date, and location | ✅ |
| Contact form validation | ✅ |
| Bootstrap components (Navbar, Cards, Buttons, Forms, Alerts) | ✅ |
| Event images (placeholders) | ✅ |

## 🚀 How to Run the Project

1. Download all files to your computer
2. Open `index.html` using any browser (Chrome/Firefox/Edge)
3. Navigate between pages using the navbar
